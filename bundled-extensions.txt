# Extensions installed automatically on every launch (see modules/bundled_extensions.py).
#
# Format, one per line:   <folder name>   <git URL>   [commit]
#
# On start, launch.py installs each listed extension that is not in the extensions folder yet:
# it clones the repository (with submodules) and checks out the pinned commit, so every install
# gets the same, tested code. The extension's own install.py then installs its Python packages,
# as for any extension. Extensions already present are left alone: update them from the
# Extensions tab as usual.
#
# An extension you remove from the extensions folder stays removed; delete
# extensions/.bundled-extensions.json to have every missing one installed again. Disable one in
# the Extensions tab to keep it installed but not loaded. --skip-bundled-extensions turns all of
# this off.
#
# To add one, append a line; to move one to a newer version, change its commit (or drop the
# commit to take whatever is current when it is first installed).
